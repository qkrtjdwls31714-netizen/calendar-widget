개인정보처리방침

캘린더 위젯 · 최종 수정 2026년 11월 18일

캘린더 위젯(이하 "위젯")은 사용자의 윈도우 PC에서 실행되는 개인용 프로그램입니다. 위젯에는 서버가 없으며, 만든 사람을 포함한 누구에게도 사용자 데이터를 보내지 않습니다.

1. 위젯이 쓰는 구글 데이터

사용자가 구글 로그인에서 허용한 범위 안에서, 위젯 화면에 보여 주고 사용자가 시킨 대로 고치는 데에만 씁니다.

권한쓰는 곳
Google 캘린더 보기·일정 수정캘린더에 일정을 보여 주고, 사용자가 일정을 만들거나 고치거나 지울 때
위젯이 만든 캘린더 관리할 일 알림을 휴대폰에서 받도록 "할 일 알림" 캘린더를 만들고 그 안의 일정을 관리할 때
Google Tasks(할 일)할 일 목록을 보여 주고 추가·수정·완료·삭제할 때. 마감 시각은 할 일 메모란 첫 줄("⏰ 15:00")에 적습니다
위젯이 만든 Google 드라이브 파일만메모장을 "위젯 메모장" 문서 하나와 맞출 때. 다른 드라이브 파일은 볼 수 없습니다

2. 저장하는 곳

  • 일정·할 일·메모 원본은 사용자의 구글 계정에 있습니다.
  • 로그인 토큰, 위젯 설정(색·알림 시각·창 위치 등), 메모 사본, 오류 기록은 사용자 PC의 %APPDATA%\CalendarWidget 폴더에만 저장됩니다.
  • 위젯은 이 데이터를 다른 서버나 제3자에게 보내지 않고, 광고·분석·판매에 쓰지 않으며, 사람이 열람하지 않습니다.

3. Google API 서비스 사용자 데이터 정책

위젯이 Google API로 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요구사항을 포함해 그 정책을 따릅니다.

4. 권한 끊기와 데이터 지우기

  • 구글 권한 끊기: myaccount.google.com/permissions에서 이 앱을 삭제합니다.
  • PC의 위젯 데이터 지우기: %APPDATA%\CalendarWidget 폴더를 삭제합니다.
  • 위젯이 만든 "할 일 알림" 캘린더와 "위젯 메모장" 문서는 구글 캘린더·드라이브에서 직접 지울 수 있습니다.
